# 🤖 Bot de Automação em Python

Este projeto é um bot desenvolvido em Python com foco em automação de tarefas e execução de processos repetitivos de forma programática.

## 🚀 Funcionalidades

- Automação de tarefas no computador
- Execução de ações repetitivas via script
- Estrutura simples e modular para expansão
- Base para integração com outras ferramentas

## 🛠️ Tecnologias utilizadas

- Python
- PyAutoGUI (ou outras libs que tu estiver usando)
- Time
- OS (se tiver usado)
